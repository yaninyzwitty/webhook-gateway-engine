# Plan: Scaffold `internal/domain/delivery.go`

## Goal
Create a pure-domain Go file at `internal/domain/delivery.go` with no database, HTTP, or heavy external dependencies.

## Context
- **Module path:** `github.com/yaninyzwitty/webhook-gateway-service`
- **Pgx version:** `v5` (includes `pgtype` for nullable types)
- **`internal/domain/`** is currently empty.

## Steps
1. Create `internal/domain/delivery.go`.
2. Define a string-based enum type `DeliveryStatus` and typed constants for:
   - `DeliveryStatusPending`
   - `DeliveryStatusAttempting`
   - `DeliveryStatusDelivered`
   - `DeliveryStatusFailed`
   - `DeliveryStatusRetrying`
   - `DeliveryStatusExhausted`
3. Define the `Delivery` struct with fields:
   - `ID` (`uuid.UUID`)
   - `EventID` (`uuid.UUID`)
   - `EndpointID` (`uuid.UUID`)
   - `Status` (`DeliveryStatus`)
   - `Payload` (`[]byte`)
   - `IdempotencyKey` (`string`)
   - `AttemptCount` (`int`)
   - `MaxAttempts` (`int`)
   - `NextRetryAt` (`pgtype.Timestamptz` — nullable time field)
   - `CreatedAt` (`time.Time`)
   - `UpdatedAt` (`time.Time`)
4. Add a `CanRetry() bool` method on `Delivery`. The logic is natural to the type: return true when `AttemptCount < MaxAttempts` and `Status` is one of the retryable states (`failed`, `retrying`).
5. Use only the standard library, `github.com/google/uuid`, and `github.com/jackc/pgx/v5/pgtype`.

## Notes
- No database imports (`database/sql`), no HTTP imports (`net/http`).
- No business logic beyond what naturally belongs on the type.
